## 重点项目

### [Project Atlas](https://github.com/h1czvk0/project-atlas)

面向开发者的本地优先项目理解助手。可以将公开 GitHub 仓库克隆到独立 Workspace，解析源码、README、配置、依赖和 Git 历史，并结合上传的项目文档建立可检索知识库。

- 使用 **FastAPI + Vue 3** 构建前后端，支持 **SQLite / MySQL**。
- 实现文档分块、轻量向量化与混合检索，为回答提供可追溯的项目证据。
- 通过 Agent 工具完成知识检索、新人上手规划、项目任务和故障记录查询。
- 接入 OpenAI-compatible API，支持多轮对话、推理强度配置和 SSE 流式输出。
- 实时展示上下文读取、证据检索、工具调用和回答生成过程，并保存历史会话。
