# h1czvk0

这里记录我长期维护的个人工具、游戏相关资料与网络课程实验。

## 个人项目

- [SLSC](https://github.com/h1czvk0/slsc)：持续维护的 Windows 本地游戏日志辅助工具，提供桌面 HUD、日志绑定、统计展示和自动更新。
- [Ecliptica Wiki 中文版](https://github.com/h1czvk0/ecliptica-wiki)：整理和维护 Ecliptica 中文攻略资料，并部署为静态站点。

## 课程与实验

- [Packet Tracer AI Ops Exporter](https://github.com/h1czvk0/packet-tracer-aiops-exporter)：从 Cisco Packet Tracer 只读导出拓扑、接口和部分配置数据，生成结构化 JSON。
- [智慧楼宇网络运维助手](https://github.com/h1czvk0/gpustack-aiops)：个人课程设计，读取上述导出数据，为拓扑分析和故障排查提供推断式辅助，结论需回到 Packet Tracer 验证。

具体用途、运行方式和已知限制见各项目 README。
